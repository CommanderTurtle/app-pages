About
Aether NDSv1.0 - Nintendo DS emulator shell.
Built for DeSmuME/melonDS WebAssembly cores.

Architecture:
- WASM core: Emscripten-compiled DeSmuME or melonDS
- Dual screen: HTML5 Canvas x2 (top + bottom)
- Touch: Mouse event simulation on bottom screen
- FS: Emscripten MEMFS + IndexedDB persistence
